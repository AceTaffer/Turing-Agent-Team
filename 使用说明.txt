 Turing Agent Team (TAT) v0.1.0 · 使用说明（M1 开发预览）
════════════════════════════════════════════════════════════

【这是什么】
Turing Agent Team 是 Open Agent Team（作者 Acct）的进阶版：
桌面端 + 安卓手机端互联——出门在外也能用手机查看、操控家里的 AI 团队。
本软件开源免费；名称致敬艾伦·图灵（无官方关联）。

【电脑端启动】
  1) 安装 Node.js（18+，推荐 24）：https://nodejs.org
  2) 双击「启动工作站.bat」→ 浏览器自动打开 http://127.0.0.1:3411
     （默认端口 3411，可与 Open Agent Team 的 3410 同时运行）
  3) 也可双击「启动桌面版.bat」使用独立窗口

【手机连接（同一 Wi-Fi）】
  1) 设置 → 手机连接 → 勾选「局域网监听」→ 点「重启服务使监听生效」
  2) 点「生成配对码」：
     · 扫码：用手机系统相机扫二维码，自动配对并进入手机端页面
     · 或：手机浏览器打开页面提示的地址（如 http://192.168.x.x:3411），
       输入 6 位配对码（5 分钟有效）
  3) 配对成功后即可：
     · 手机端对话（AI 调用走电脑代理，API Key 不会同步到手机）
     · 查看/控制团队任务：暂停 / 继续 / 终止 / 中途指令 / 与单个角色对话
     · 批准 AI 的权限申请、回答 AI 提问
     · 断线不暂停：手机切后台或断网，电脑端任务照常运行，重连后完整回放

【手机连不上？】
  · 确认手机与电脑在同一 Wi-Fi（或已用 EasyTier 组网）
  · 检查 Windows 防火墙：设置 → 手机连接 →「手机连不上？防火墙设置」，
    按提示允许 Node.js 入站（专用网络）

【异地使用（可选）：EasyTier 组网】
  1) 设置 → 手机连接 → EasyTier 区：点「一键下载安装」（从官方 Release 下载）
  2) 填写网络名称 / 网络密码 / 本机虚拟 IP（默认 10.126.126.1）
  3) 点「启动组网」→ 在电脑上确认管理员授权（UAC 弹窗）
  4) 手机安装 EasyTier 官方 Android 客户端，加入相同网络名/密码，
     然后用手机浏览器访问 http://本机虚拟IP:3411

【安全说明】
  · 手机访问需要配对令牌；设备权限分档（只读 / 可操作 / 可批准 / 可配置）
  · 可在「手机连接」中随时撤销设备（立即失效）
  · 异地建议使用 EasyTier（端到端加密）；局域网内为 HTTP+令牌
  · 远程操作有审计日志：data/audit.jsonl
