# Turing Agent Team (TAT) · 0.1.0（M1 开发预览）

> 致敬计算机科学与人工智能之父 **艾伦·图灵（Alan Turing）**。
> 名称仅为致敬，与 Alan Turing 遗产管理机构及图灵研究所**无任何官方关联**。

Turing Agent Team 是 [Open Agent Team](https://github.com/AceTaffer/Open-Agent-Team)（作者 Acct）的进阶版：
**桌面端 + 安卓手机端互联**，让你出门在外也能监控/操控家里的 AI 团队。

## 特性
- **桌面端完整能力**（继承自 Open Agent Team）：API 仓库/余额、多智能体团队任务、技能与插件、统计、画布/视频工具、热更新等
- **手机互联（M1 已完成）**：
  - 局域网配对：6 位 PIN + 二维码（手机系统相机扫码即可，无需网页摄像头权限）
  - 设备令牌与权限档（只读 / 可操作 / 可批准 / 可配置），设备可命名、撤销
  - 手机端对话（走电脑代理调用 AI，API Key 不出电脑）
  - 远程监控与控制团队任务：暂停 / 继续 / 终止 / 中途指令 / 角色单独对话
  - 手机端批准权限申请、回答 AI 提问
  - **断线不暂停**：手机切后台/断网不会打断电脑端任务；重连后完整回放（事件落盘）
  - 跨设备同步：数据变更实时广播，多设备自动刷新/提示
- **异地接入（可选）**：EasyTier 一键引导（LGPL-3.0 开源，官方下载 + 独立进程调用）；后续版本支持 cloudflared 隧道

## 快速开始（电脑端）
1. 安装 Node.js（18+，推荐 24），双击 `启动工作站.bat`（默认端口 **3411**，可与 Open Agent Team 的 3410 同时运行）
2. 打开「设置 → 手机连接」→ 勾选「局域网监听」→ 点「重启服务使监听生效」
3. 点「生成配对码」：
   - **扫码**：手机与电脑同一 Wi-Fi，用手机系统相机扫描二维码，自动配对并打开
   - **PIN**：手机浏览器访问提示的地址，输入 6 位配对码（5 分钟内有效）
4. 手机端即可聊天、查看/控制团队任务、处理权限申请

## 手机端说明
- 当前形态：**移动端网页（PWA 基础）**，手机浏览器直接使用；安装版 App（Capacitor + 推送 + 离线直聊）在后续里程碑
- 连不上时：检查 Windows 防火墙是否允许 Node.js 入站（专用网络）；设置页「手机连接 → 手机连不上？防火墙设置」可一键复制放行命令
